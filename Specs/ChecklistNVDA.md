# Checklist NVDA — AccessTest

À dérouler avec NVDA sur .NET 10, puis sur .NET Framework 4.8 : pour chaque ligne, noter si NVDA annonce bien ce qui est attendu et reporter l'écart dans la colonne **Résultat** (conforme ou non, framework testé, ce que NVDA annonce). Colonne vide : pas encore testé.
Les fichiers de `Specs/` renvoient à ces points par leur numéro (« Points de la checklist qui concernent cet onglet »). Ce fichier se lit pour préparer ou noter un test, pas à chaque session.
